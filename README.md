# Soul Vibe Space — фронтенд

Статический сайт студии. Деплоится на Netlify автоматически при пуше в `main`.

- Живой сайт: https://soul-vibe-space.netlify.app
- Netlify site ID: `5160c45c-80d9-4a82-9a3d-068717d5fdc2`
- Бэкенд API: https://soul-vibe-api.onrender.com (репозиторий `soulvibespace/soul-vibe-api`)

## Как вносить правки

```bash
git clone git@github.com:soulvibespace/soul-vibe-site.git
# правим файлы
git commit -am "что изменили"
git push origin main   # Netlify подхватит и опубликует сам
```

Сборки нет: `deploy.py` считает контрольные суммы файлов, догружает только
изменившиеся и публикует деплой. Настройки кэша и заголовков безопасности лежат в
`netlify.toml` — они применяются и при таком способе публикации (проверено).

### Как это устроено
Репозиторий публичный, поэтому Netlify собирает его бесплатно: пуш в `main`
запускает публикацию автоматически, ничего вручную запускать не нужно. Сборки как
таковой нет — Netlify выкладывает корень репозитория как есть.

Сборка `build.sh` собирает папку `dist/` только из файлов сайта, чтобы README,
скрипты и конфиг не оказались доступны по прямой ссылке.

Резервный путь: `python3 deploy.py` собирает то же самое и заливает через API, минуя
сборку на стороне Netlify.
Нужен, если автодеплой почему-то не сработал или надо выложить состояние, которое
ещё не в `main`.

Репозиторий сделан публичным осознанно: код фронтенда целиком отдаётся браузеру
любого посетителя, секретов в нём нет (проверено поиском по файлам и по всей
истории коммитов). Бэкенд `soul-vibe-api` остаётся приватным — вся логика,
ключи и доступы к Simplybook живут там.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Главная |
| `schedule.html` | Расписание, тянет данные из `/api/schedule` |
| `classes.html`, `pricing.html`, `about.html`, `space.html`, `contact.html` | Контентные страницы |
| `account.html`, `account.js` | Личный кабинет: брони, отмена |
| `auth-modal.js` | Вход и регистрация |
| `booking-modal.js` | Запись на занятие |
| `i18n.js` | Переводы EN / RU / EL |
| `app.js` | Общая логика, навигация |
| `style.css` | Все стили |
| `privacy.html`, `terms.html`, `cookie-banner.js` | Юридические страницы и согласия |
| `netlify.toml` | Кэш и заголовки безопасности |
| `build.sh` | Собирает `dist/` из файлов сайта (на сайт не попадает) |
| `deploy.py` | Резервная публикация через API (на сайт не попадает) |

## Важно

**Не заливать ZIP-архивы вручную.** До августа 2026 сайт обновлялся именно так,
из-за чего появились три разошедшиеся копии и правки терялись. Теперь
единственный источник истины — этот репозиторий: что не в `main`, того на сайте
нет. Старые копии убраны в `_archive/` в рабочей папке.

При импорте содержимое репозитория сверено с живым сайтом по контрольным суммам:
все 28 файлов совпали байт в байт, ничего не потеряно и не откатилось.

Домен `soulvibespace.com` пока указывает на старый сайт на Squarespace. Перенос —
отдельная задача после того как новый сайт будет доделан.
